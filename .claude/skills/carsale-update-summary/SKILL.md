# CarSale: обновление сводки

Рабочая папка: ~/ClaudeProjects/CarSale. Готовая реализация: `python3 update_summary.py` (пишет `report.json`).

## Файлы (точные имена)
- Источники: `cross-polo_avto-riа-com.md` (AUTO.RIA, буква «а» в «riа» кириллическая), `cross-polo_olx-ua.md` (OLX.ua). Если имя не совпало — найти по маске `cross-polo_*.md` и сообщить, какой файл взят.
- Сводка: `cross-polo-summary.md` (одна таблица, колонки не менять):
  `| Дата и время (UTC) | Источник | Модель | Год | Госномер / ID | Л.с. | Объем двигателя | Пробег | Цена, $ | Город | Ссылка |`

## Шаги
1. Из каждого источника взять записи самой свежей даты. Если на машину несколько снимков за день — оставить самый поздний.
2. Ключ машины = Госномер/ID (для OLX — ID объявления). Ссылка и пробег в ключ не входят.
3. Для каждой машины: если в сводке уже есть запись с тем же ключом и той же датой (календарный день UTC) — пропустить, иначе добавить строку.
4. Отсортировать всю таблицу: дата и время по убыванию, при равенстве AUTO.RIA выше OLX.ua. Новые строки — сверху.
5. Классификация добавленных строк относительно предыдущей записи того же ключа:
   - записи раньше не было → «НОВОЕ»;
   - цена отличается → «ЦЕНА» (было → стало), даже если изменился и пробег;
   - иначе → «без изменений».
6. Результат — `report.json` (sources, added[row, cls, was], chart).

Отчёт: сколько строк добавлено, какие НОВОЕ/ЦЕНА.
